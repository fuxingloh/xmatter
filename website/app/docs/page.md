# Xmatter

Structured metadata for address and smart contracts; building the frontpage for an address.

## Motivation

Help you build the frontpage for an address.

## Network Icons?

If you need a beautifully crafted crypto icon library for Tokens, Networks, and Wallets,
you should check out [0xa3k5/web3icons](https://github.com/0xa3k5/web3icons).
This library focuses on a separate problem space.
